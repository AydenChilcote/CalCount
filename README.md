# Calorie Tracker

A mobile-friendly calorie tracking web app built with Next.js and TypeScript.

## Features

- **Daily Calorie Goal**: Track up to 2000 kcal per day, with automatic reset at midnight.
- **Add Food**: Easily add new foods with title and calorie count.
- **Daily Food List**: View all foods consumed today.
- **Food Library**: Store and quickly re-add previously entered foods.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the app.

## Deployment

This app can be deployed to Vercel, Netlify, or GitHub Pages.

For Vercel (recommended):

1. Push to GitHub
2. Connect to Vercel
3. Deploy

## Technologies

- Next.js
- TypeScript
- Tailwind CSS
- Local Storage for data persistence
